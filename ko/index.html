Apple 받아쓰기에서 옮기시나요?

Apple 받아쓰기는 macOS에 내장되어 있어 많은 분들에게 충분합니다. Wavetype은 전용 도구가 필요한 경우를 위한 것입니다.

원하는 만큼 말하세요

키를 누르고, 말하고, 떼세요. 한 문단이든 이메일 전체든 — 한 번에 처리합니다. 시간 제한도, 자동 중지도 없습니다.

설정 없이 다국어

Whisper가 99+ 언어를 자동 감지합니다. 문장 중간에 한국어에서 영어로 바꿔도, 받아쓰기가 따라갑니다.

항상 100% 로컬

처음 모델 다운로드 후에는 인터넷 없이 작동합니다 — 비행기에서, 터널에서, 오래된 MacBook에서. Apple ID 없이, 클라우드 왕복 없이.

자동으로 들어가는 문장부호

Whisper가 쉼표, 마침표, 단락 구분, 대문자를 자동으로 추가합니다. 그냥 말씀하세요 — 모델이 나머지를 처리합니다.

자주 묻는 질문

정말 인터넷 없이 작동합니까?

예. Whisper는 whisper.cpp를 통해 Mac에서 완전히 실행됩니다. 첫 모델 다운로드(품질에 따라 75MB–1.5GB) 후에는 비행기에서, 터널에서, Wi-Fi 꺼진 상태에서 — 어디서든 받아쓰기가 작동합니다.

얼마나 비공개입니까?

음성과 변환 결과가 기기를 떠나지 않습니다. 클라우드 서버 없음, 분석 없음, 계정 없음, 텔레메트리 없음. 활성 상태 보기의 네트워크 탭에서 확인할 수 있습니다 — Wavetype의 송신 트래픽은 0으로 유지됩니다.

App Store 버전 vs Pro — 어느 것?

App Store 버전은 샌드박스(Apple 규칙)에서 실행되며 클립보드에 복사하고 Cmd+V를 누릅니다. Pro는 자동 붙여넣기를 추가합니다 — 텍스트가 커서가 있는 필드에 바로 들어갑니다. 가장 매끄러운 워크플로를 원한다면 Pro를 선택하세요.

다른 언어는?

Whisper는 99+ 언어를 지원하고 말하는 언어를 자동 감지합니다. 앱 인터페이스 자체는 14개 언어로 현지화되어 있습니다.

정확도는?

Wavetype은 세 가지 Whisper 모델 등급을 제공합니다: Ultra Fast(영어 전용, 가장 작음), High(large-v3-turbo, 기본값 — 받아쓰기, 억양, 전문 용어를 잘 처리), Maximum(전체 large-v3, 더 느림, 최고 정확도).

환불은?
